# OYB theme for AMP

AMP's store only lists CubeCoders' own themes, and refuses to apply one whose
file has been edited. So the OYB look goes in through a store theme that is
already active:

1. In AMP's Store, apply **Black** (untouched).
2. File Manager → WebRoot → Themes → AMPThemes → Black → open `Black.css`.
3. Replace everything in it with `OYB/OYB.css` and save.
4. Ctrl+F5.

If a store update puts Black back, repeat step 3.
