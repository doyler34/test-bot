{% if here == 0 %}

Server manager

Welcome, {{ user.username }}

As a manager you run the servers from here instead of AMP. This short walk-through shows you round. It only appears once, and you can take it again any time from Guide.

The summary

The top row counts the servers running, the players on, and the memory in use across the whole box.

One card per server

Each card shows whether the game is Running, Stopped or AMP off, plus its players, map, memory, mods and admins. Open goes to that server's own tabs. Press Start AMP first if its AMP is off.

{{ hint() }}
{% elif here == 1 %}

Start, restart, stop, update

These run the game server itself. Restart and Stop kick everyone on it, so they ask you first. Update stops the game while it downloads the latest version.

The numbers

CPU, memory and players, read live from AMP while the game runs.

AMP itself

AMP on or off is the server's manager, not the game. Only stop AMP when AMP is stuck: it stops the game too. Deleting a whole server is at the bottom, for the panel's owners only.

{{ hint() }}
{% elif here == 2 %}

The live console

This is the game's own log, newest at the bottom. It refreshes every few seconds, and you can scroll back up to read it.

Full screen

Tap ⤢ for the whole screen. Tap ✕ or outside the box to come back.

Send a command

Type anything the game understands, like #players, and press Send. It goes through AMP and into the audit log.

{{ hint() }}
{% elif here == 3 %}

Every setting, in sections

Basics, Admins, Mods, Gameplay, Performance, Saves, Network, then AMP's own. Jump to one with the buttons at the top, or type in the search box, for example view or save.

Change a value

Type a new value, or flip a switch. The row is marked as you change it, and the counter at the bottom says how many changes are waiting.

In-game admins

Each admin shows by name. Remove takes one off. Add takes a name you type, or one tap for anyone marked as admin in the panel. They don't need the admin password.

Save

Press Save changes to write them to AMP. Most take effect when the server next restarts. Passwords are never shown: type a new one to change it.

{{ hint() }}
{% elif here == 4 %}

The mods a server loads

Each one is listed with its ID. Downloaded but not loaded means it's on the box and can be put back with one tap.

Add or remove a mod

Paste the mod's 16-character ID from its Workshop page and press Add. Remove takes it off the list. Changes apply when the server next starts.

{{ hint() }}
{% elif here == 5 %}

Shortcuts

The config, the mods folder and the game logs are one tap away.

Upload, make and tidy

Upload files into the folder you're in, or make a new folder or file. Tap a file to open it, edit, and press Save.

Careful with serverconfig.json

AMP writes that file from its settings every time the server starts, so change those values in Settings instead.

{{ hint() }}
{% elif here == 6 %}

Make a new server

Work down the seven steps. Pick a server to copy from and everything fills in with its values. Tick Start it when ready to have it run by itself once the game has downloaded. Its progress shows on the Server manager.
