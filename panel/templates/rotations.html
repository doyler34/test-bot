Rotations

A rotation is a game set up once and kept: points moved with GM, the kill feed and other GM settings, and the MOBs the game picked. When rotations are on, each game over loads the next one (the server restarts, about a minute). To make one: start a game, set it up with GM, wait for the next autosave (every 10 minutes), then save it here. Do it at the start of a game with nobody else on, as everything in the save comes back.
