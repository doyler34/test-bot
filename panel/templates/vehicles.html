Limit groups

Each group is an allowance per side: with Helicopters at 2, each side can have at most 2 live vehicles from that group at once (a vehicle's variants count as the vehicle). Bought vehicles count for the side whose depot sold them, whoever drives them; wrecked or deleted ones stop counting. Vehicles in no group, and groups with an empty limit, are unlimited; 0 allows none. Game Master vehicles don't count, except that when the server starts every live vehicle already in the world counts once for its own side. Lowering a limit never removes vehicles.
