Banning

Type part of their name and pick them from the list, choose how long, pick or type a reason, and press Ban on all servers. It applies to every server at once, and they're told how to appeal.

Every ban is an IP ban: it also catches their alts and any new account from the same IP. People in the same house share an IP, so be sure before you ban.

{% endif %}

Every ban

Who, why, how long is left, who did it, and whether each server has it yet. {%- if not can("ban") %} Banning is for admins: if someone needs one, kick them, leave a note saying why, and ask an admin. {%- elif not can("unban") %} Taking a ban off is for senior admins: ask one if a ban was a mistake. {%- else %} Remove unbans on every server, and Edit changes the reason or length.{% endif %}

Data

The pages for looking into the panel, the box and who's been trying to get in.

Audit log

Every action in the panel with who did it and when: logins, kicks, bans, restarts and settings changes. The answer to "who did that?"

Box dashboard

Everything the machine is doing, charted over up to a week. Its Network check tab is the first stop when players say it's laggy: it finds dropped packets and gives you the exact fix.

Login attacks

Failed logins on SSH, AMP and this panel. Add your own address under Admin IPs so your typos are never flagged. IP lookup says who an address belongs to.

Always here

Data stays in the menu on the leftunder More.

Settings

A card for each thing you can change. Each one goes in the audit log with your name.

Server cards

The picture, description and join address on each server's card. The join address is what gives everyone the copy and Join buttons.

Sus settings

How touchy the cheat checks are. Higher numbers mean fewer flags; Reset to defaults puts them back.

In-game admins

Make players admin in game on each server, through AMP. It applies when the server next restarts.

Admins

Panel accounts and roles. Edit access next to someone switches single things on or off just for them, like the Box dashboard for one moderator, without making them senior admin.

Website

The public site's words, servers and rules. It changes the moment you save.
