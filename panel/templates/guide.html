The OYB Control guide

Welcome to OYB Control

This is where we run the OYB servers: watching games as they happen, dealing with players, catching cheaters and keeping the servers healthy. Here you'll find everything you need to GM with it.

We built OYB Control ourselves so we have the freedom to add whatever we want, instead of being stuck with what someone else's tool gives us. Everything in it is here because we needed it. If you find yourself wishing it did something, tell an owner: it can be added.

New here? Start with Getting started, then read the rest in order or jump to what you need. The pictures come from a demo with made-up players, so the names won't match our servers.
