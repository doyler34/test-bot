Servers

The home page shows every server with its status, player count and memory. Click one to open it.

  • Controls along the top: Restart mission starts a new game without restarting the server program. Shut down (RCON) stops the game from inside. Start / Stop / Restart server control the whole server program. Every button asks you to confirm first, because everyone on is affected.
  • Summary strip: players on, RCON ping, server FPS, memory, uptime over the last day and how long it's been running. It refreshes every 10 seconds.
  • Tabs: Overview (players, live feed, recent actions), Health and History.
  • Every box has a ⤢ button in the corner to go full screen. Press Esc to close it.

Live feed

Everything happening in game, newest first, refreshing every 5 seconds: joins and leaves, side picks, kills and teamkills (with distance, and the damage type when it isn't a bullet), messages from the server, and admin actions.

Use the chips to filter: Joins, Kills, Sus, Admin and RCON.

Spotting cheaters

The panel watches the logs for the patterns we found when we caught a cheater spawning explosions. Anything that trips a check shows up as a red Sus row in the live feed and is posted to the staff Discord channel.

  • Explosions credited to AI: players dying to explosions with no named killer, so nothing in the kill feed. It flags 3 in the same second, or 5 within 5 minutes.
  • Script error spike: the server failing to spawn players properly, over and over.
  • Rapid kills: 6 rifle kills in 30 seconds.
  • Headshots: 10+ kills in 15 minutes with three quarters or more to the head.
  • Teamkill spree: 3 teamkills in 10 minutes.

An explosion or error flag waits 2 minutes, then tells you who joined just before and who was killing nearby. It also saves everyone who was online. If the same player is on for incidents again, on any server, the flag says so ("At earlier incidents too: Name (2x)"), and their player page lists every incident they were present for.

A flag is a reason to spectate, not proof. The logs never say which weapon was used, and gunships and grenade launchers can look odd too. One flag with someone's name in it means little; the same name at several is worth a close look.

Players

Search anyone who has ever joined by name, an old name or their identity ID{% if can("ips") %}, or by IP{% endif %}. A player's page shows:

  • Time played, kills, deaths, K/D, teamkills and recent games, and their linked Discord account.
  • Names they've used, first and last seen, ban history and admin notes. Leave a note whenever you deal with someone so the next admin knows.
    • {% if can("ips") %}
  • Connections: every IP they've played from, their BattlEye GUID, and every other account seen on the same IP. That's how alts and ban evaders show up. In the live player list, a pill marks players with other accounts, red if one of them is banned.
    • {% endif %}
  • Any suspicious incidents they were online for.

Players on PC, PlayStation and Xbox get a different identity ID on each, so one person can have several accounts. Shared IPs are how you link them.

Kicking

Use the Kick button on a player's row in the server's player list. They can rejoin straight away, so use it for a warning or to sort out a bug, and ban for anything more.

Bans

{% if can("ban") %}
  • Go to Bans, start typing the player's in-game name and pick them from the list. Players online come first. You can paste an identity ID instead.
  • Pick a length and give a reason. The ban goes to every server at once and kicks them if they're on. A server that's offline picks it up when it's back.
  • IP ban also bans every other account seen on their IPs (PC, PlayStation, Xbox, alts), and bans and kicks any new account that joins from one of those IPs later. People in one house share an IP, so leave it unticked when that matters.
  • If the player has linked their Discord, the bot gives them a Banned · length role so everyone can see it, and takes it off when the ban ends.
  • To unban, press Unban next to the ban. IP bans are undone one account at a time.
{% else %}

Bans need an admin. Kick the player and ask an admin, and leave a note on their player page saying what happened.

{% endif %}

History

Every game is saved when the server next restarts, whole log folder and all, and kept for good. Open a server's History tab to see the last week's games, or pick any day.

Opening a game shows who played (when they were on, and their kills, deaths and teamkills), the whole feed with the same filters as the live one, admin actions during it, and the suspicious-activity checks run with today's settings.

{% if can("ips") %}

You can download a game's log folder from its page, and upload an old console.log at the bottom of the History tab to add a game from before the panel was running.

{% endif %}

Health

  • Uptime over the last day and week, crashes (the server stopping without anyone pressing a button), and recent starts and stops.
  • Memory: a graph of the last 24 hours. A few minutes after a full server restart the panel notes what a clean server uses.
  • After Restart mission, the panel checks memory again once the new mission has loaded. If it's still well above a clean start, the old mission's memory wasn't let go, and it's time for a full Restart server. A bit higher than a clean start is normal.
  • The real sign of a leak is memory that climbs higher after every mission restart. A full server restart every 6–12 hours keeps it in check.

Discord

  • Bans, unbans, kicks, restarts, crashes, a server going down or coming back, memory that didn't clear, and sus flags are posted to the staff channel.
  • Players link their game account to Discord through the bot. Anyone who has played on one of the servers can link.
