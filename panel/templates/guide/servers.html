The power buttons

At the top, next to how fast the server's answering:

ButtonWhat it doesWhen to use it
StartStarts the server when it's off.After a Stop, or if it crashed and didn't come back.
RestartStops and starts the whole server. Everyone is disconnected for a minute or two.Memory didn't clear, the server's laggy, or every 6–12 hours to keep things fresh.
StopStops the server. It stays off until someone starts it.Maintenance.
UpdateHas AMP stop the server and update the game.After a Reforger update, when players can't join on the new version.

{% if can("power") %}Restart, Stop and Update ask you to confirm, and go in the audit log and the staff Discord channel with your name. They work once the panel is connected to AMP.{% else %}The power buttons are for senior admins, or anyone a senior admin gives the start and stop permission. For everyone else they're greyed out.{% endif %}

The summary bars

Under the name: players on (and slots), CPU and memory with a bar each, and how long it's been up.

Tabs

{{ shot("server-tabs", "The tabs.") }}
  • Overview: the same panel as on the dashboard: information, live map, players and charts.
  • Live feed: the full-size player list (with Kick{% if can("ban") %} and Ban{% endif %}), the live feed, and recent admin actions on this server. This is the tab for dealing with people.
  • History: every past game. See Past games.
  • Health: uptime, crashes and memory. See Health and memory.
  • Monitor: a reading every 15 seconds for a week, for working out lag.

The Live feed tab

The strip at the top updates every 10 seconds:

  • Players on, right now.
  • Admins on, with their names. Red 0 means nobody's watching. The panel counts players listed as admins in the server's own config, and anyone a senior admin marked with Mark as admin on their player page.
  • Ping (RCON): how fast the server answers the panel. A big number means it's struggling.
  • Server FPS: below 20 turns red and players will feel lag.
  • Memory, Up, last 24h and Running for.

The Players box lists everyone on now, A to Z. Type in Search players to cut the list down; an Admin tag marks admins.
