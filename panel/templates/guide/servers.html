The controls

The buttons along the top act on the whole server, so they affect everyone playing. Each one asks you to confirm first.

{{ shot("server-top", "The controls (outlined) and the summary strip under them.") }}
ButtonWhat it doesWhen to use it
Restart missionEnds the current game and loads a fresh one, without restarting the server program. Quick, and nobody has to reconnect to the server.End of a round, or the game has got into a bad state.
Shut down (RCON)Tells the game to shut itself down.Rarely. Stop server is usually better.
Start serverStarts the server program when it's off.After a Stop, or if it crashed and didn't come back.
Stop serverStops the server program. It stays off until someone starts it.Maintenance.
Restart serverStops and starts the whole server program. Everyone is disconnected for a minute or two.Memory didn't clear after a mission restart, or every 6–12 hours to keep things fresh.

The controls are for admins and owners. Moderators don't see them.

The summary strip

Updated every 10 seconds:

  • Players on, right now.
  • Ping (RCON): how fast the server answers the panel. A big number means the server is struggling.
  • Server FPS: how smoothly the server is running. Below 20 turns red and players will feel lag.
  • Memory the server program is using.
  • Up, last 24h: how much of the last day it was online.
  • Running for: time since the server program last started.

Tabs

{{ shot("server-tabs", "The three tabs.") }}
  • Overview: the players on now, the live feed, and recent admin actions on this server.
  • Health: uptime, crashes and memory. See Health and memory.
  • History: every past game. See Past games.

Full screen

Every box has a ⤢ button in its top right corner. Press it to blow the box up to fill the screen, which is handy for reading a busy live feed. Press Esc or the button again to put it back.
