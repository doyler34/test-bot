{{ shot("tutorial/01-discord-home", '🛠️ OYB Control: the Discord section') }}

Everything the OYB bot says and does in our Discord is changed from the panel. No code, no restarts.

Where: log in at panel.oybgaming.com and press DISCORD in the top menu.

The Discord page lists every part in groups:

  • What new members see: Start here, Join greeting, Server info & rules, Factions
  • What the bot posts by itself: Match alerts, Weekly top 3, Ban messages, Staff alerts
  • Posting yourself: Posts
  • Staff jobs: Link requests, Feedback
  • Setup: Channels & roles, Server names

Each one has a status in the corner:

🟢 Live: Discord shows your version

🟡 Draft not published: someone saved changes but hasn't pushed them out

⬜ Bot's default: never changed, the bot's built-in wording (that's fine)

🔴 Problem: the bot couldn't do it; open the page to see why

Who can use it: owners, plus anyone an owner gives Discord access to under Admins → Edit access (all Discord pages, or just some).

📍 Picking a channel

{{ shot("tutorial/02-channel-box", '📍 Picking a channel') }}

Pages for something the bot keeps in a channel have a Channel box at the very top: Server info & rules, Factions, Match alerts, Weekly top 3, Staff alerts, Feedback and Link requests.

  1. Pick the channel from the list.
  2. That's it. It saves the moment you pick it and you'll see "Channel changed".
  3. Within a minute the bot takes its message down from the old channel and puts it up in the new one.

Good to know

  • The channel box is separate from Publish. Publishing a page never changes its channel, and changing the channel never needs a publish.
  • The first option in the list is what the bot does with nothing picked, e.g. "The bot's own #servers channel".
  • The bot uses the channel as it is: it won't rename it or change who can see it. So make sure the bot can post there, and that staff channels (staff alerts, feedback inbox, link requests) really are staff only.
  • Start here, Join greeting, Ban messages and Posts pick their channel inside the page instead.

💾 Draft, then publish

{{ shot("tutorial/03-draft-publish", '💾 Draft, then publish') }}

Every page works the same way:

  • Save draft: keeps your changes without touching Discord. Other owners see the draft too, so you can leave it for someone to check.
  • Publish: sends it to the bot. Discord updates within a minute.
  • Discard draft: throws your changes away and goes back to what's live.

The box near the top always tells you where you are:

  • Not published: Discord still shows the bot's default.
  • Live: when it was published and by who, and whether the bot has picked it up yet.
  • Draft: there are unsaved changes nobody has published.

If something's wrong (a missing channel, a role the bot can't give out), Publish stops and lists what to fix, and your work is kept as a draft so nothing is lost.

Most pages have a Preview on the right. It's roughly how it'll look in Discord, and it updates as you type.

👋 Start here message

{{ shot("tutorial/04-start-here", '👋 Start here message') }}

Discord → Start here message is the first thing new members see: the rules, the button to link their game account, and the faction picker.

Where and how it looks

  • Channel: where it's posted (our 👋｜welcome).
  • Title and Stripe colour: the coloured bar down the side.

Text

It's split into sections, each with an optional heading.

  • bold, *italic* and new lines work just like in Discord.
  • ↑ ↓ move a section, ✕ removes it, + Add section adds one.

Watch the Preview on the right as you type. When you're happy, Publish. The bot edits the existing message; it doesn't post a new one.

Start again from the original at the bottom puts it back to the bot's built-in version if you ever want to start over.

🔘 Buttons (Start here and Posts)

{{ shot("tutorial/05-button-editor", '🔘 Buttons (Start here and Posts)') }}

Each button shows as one line. Tap it to open it, tap the header again to close it. + Add button makes a new one. Up to 5 buttons fit on each of 5 lines.

What it does — pick one:

  • Link Reforger account: opens the box to link their game account
  • My progress: shows them what they've done and what's left
  • Pick a faction / No faction: the US, USSR and FIA roles (Start here only)
  • Give or take a role: press to get it, press again to remove it (e.g. Event pings)
  • Pick one role from a group: buttons with the same group name work together; picking one removes the others. Tick Locked so they can't change it after.
  • Open a web link: opens a website
  • Give feedback: opens the feedback form (see Feedback)

Then set the Label, an Emoji, which Line it sits on, and the Colour.

For role buttons, pick a role from the list or choose + Make a new role… and type a name; the bot creates it when you publish. Tick Only for players who've linked to keep it for linked players.

⚠️ A button can never hand out a role with permissions (admin, kick, manage anything). Those are greyed out. The bot's own role also has to sit above any role it gives out; the page tells you if it doesn't.

🎮 Server info & rules

{{ shot("tutorial/06-server-info", '🎮 Server info & rules') }}

Discord → Server info & rules edits the card in our 🎮｜servers channel.

  • The #servers card: the title and intro at the top.
  • Each server's settings: the line under each server's live status, e.g. map, player slots, anything players should know.
  • The in-game rules: the rules card under it.

The live status (match running, waiting, offline) fills itself in; you only write the words around it.

⭐ The rules here are also the rules on our website, so change them once and both update.

A box you leave as it is keeps following the bot's own wording. Check the Preview, then Publish.

🏷️ Server names

{{ shot("tutorial/07-server-names", '🏷️ Server names') }}

Discord → Server names changes what each server is called everywhere the bot names it: the SERVER STATUS channels, the #servers card, match alerts and results, and the 🔔 match-notification buttons.

  1. Type the new name in that server's box. An empty box keeps the default shown underneath.
  2. Check the Preview on the right.
  3. Press Publish.

Good to know

  • Two servers can't have the same name.
  • A name can't contain · (the bot uses it in the channel names).
  • Discord only lets a bot rename a channel about every 5 minutes, so a SERVER STATUS channel can take that long. Everything else changes within a minute.

🚩 Factions

{{ shot("tutorial/08-factions", '🚩 Factions') }}

Discord → Factions changes how the three factions look in Discord: their name, colour and emoji.

  • The name and colour are the faction's role, so everyone who picked it changes with it.
  • The faction picker's buttons and the /rank card use the new name too.
  • The Channel box at the top is where the faction picker and the 🔔 match-ping buttons live (our 🏷️｜choose-roles).

Good to know

  • It only changes Discord. Which side someone plays in game, rank names and the rank card artwork stay as they are.
  • The bot can only rename or recolour a role that sits below its own; the page tells you if one doesn't.
  • The Start here message's faction buttons have their own labels, set on the Start here page.

🙌 Join greeting

{{ shot("tutorial/09-join-greeting", '🙌 Join greeting') }}

Discord → Join greeting is a hello when someone joins the Discord.

  1. Tick Greet them.
  2. Choose Post in a channel (everyone sees them arrive) or Send it to them privately (players with DMs off won't get it).
  3. If it's a channel, pick it.
  4. Write the message. Tap these to drop them in:
  • {user}: mentions them
  • {name}: their name
  • {server}: the Discord's name
  • {members}: how many members there are
  • {start}: a link to the Start here channel
  1. Publish.

ℹ️ The bot only hears about people joining if Server Members Intent is turned on for it in Discord's developer portal. The page warns you if it isn't.

🟢 Match alerts

{{ shot("tutorial/10-match-alerts", '🟢 Match alerts') }}

When a new match starts on a server, the bot posts a "match started" alert. Discord → Match alerts controls it.

  • Channel (top): where alerts go (our 📢｜announcements).
  • Which servers post an alert: untick a server to stop its alerts.
  • Ping the players who asked for that server's alerts: players choose which servers ping them with the 🔔 buttons. Untick to post quietly with no ping.
  • Wording: the title and message. {server} becomes the server's name.

When the match started, and when the alert disappears (30 minutes later), are always added underneath. Check the Preview, then Publish.

🏆 Weekly top 3

{{ shot("tutorial/11-weekly-top3", '🏆 Weekly top 3') }}

Every Monday at midnight Eastern the weekly leaderboard resets, and the bot posts last week's top 3 with their kills.

Discord → Weekly top 3

  • Channel (top): where it's posted. With none picked, it goes in the weekly leaderboard channel.
  • Post the top 3 each week: untick to turn it off.
  • Wording: the title, the text above the top 3 and the text below. {week} becomes the date the week started, like 28 Sep. bold and new lines work.

The top 3 and their kills always go in the middle. Nobody gets pinged. The Preview uses made-up players.

🔨 Ban messages

{{ shot("tutorial/12-ban-messages", '🔨 Ban messages') }}

Discord → Ban messages sets what a banned player is told, and what staff see in their ticket.

The DM a banned player gets (only players who've linked their Discord)

  • Send it: on or off.
  • Title and Message: tap {server}, {account} or {length} to drop those in.
  • How to appeal: use Link a channel in the appeal line to add a clickable channel, like 🎫｜open-support-ticket.
  • The reason and when the ban ends are always added underneath.

Ban card in tickets

When a banned player opens a ticket, the bot posts their ban into it: account, length, reason, who banned them, and when it ends. Staff know straight away what it's about.

  • Post it: on or off.
  • Channel with the ticket panel, plus tick any other categories tickets are made in.
  • Panel address (optional) adds a link to the player's page on the card.

Both are previewed on the right. Publish when done.

🚨 Staff alerts

{{ shot("tutorial/13-staff-alerts", '🚨 Staff alerts') }}

When one player teamkills several people in a short time, the bot posts it in the staff alerts channel straight away: who did it, on which server, and who they killed.

Discord → Staff alerts

  1. Channel (top): pick a staff-only channel, e.g. 🚨｜staff-alerts. Until one is picked, alerts wait.
  2. Teamkills and Within (seconds): how many, how fast. Default is 3 in 60 seconds.
  3. Role to ping: type a role name like Admin, or leave blank to ping nobody.
  4. Publish.

Good to know

  • Each player is reported at most once every 5 minutes, so one rampage is one alert.
  • It also shows as a Sus line in the panel's live feed.
  • Recent alerts at the bottom lists the last ones sent.

💌 Feedback (settings)

{{ shot("tutorial/14-feedback", '💌 Feedback (settings)') }}

Members send feedback with a Give feedback button. It works like a simple ticket: it lands in a staff channel, and staff can reply or mark it done.

Discord → Feedback

  1. Channel (top): where feedback lands. This must be a staff-only channel like 📥｜feedback-inbox, NOT the public 💌｜feedback channel, or everyone can read it.
  2. Topics they pick from: one per line (e.g. Servers & settings, Rules, Events, Discord, Suggestion, Other). They pick from a dropdown. Leave it empty to let them type their own.
  3. Take feedback: untick to close the form for a while.
  4. After they send it: the private thank-you only they see.
  5. DM when staff press Done: {topic} becomes what it was about. Blank sends nothing.
  6. Role to ping (optional).
  7. Publish.

When feedback comes in, each one has two buttons:

✉️ Reply by DM: type a reply and the bot DMs it to them. It's noted on the feedback.

✅ Done: turns it green, notes who dealt with it, and DMs them the thank-you.

Members can send one every 5 minutes.

📝 Posts

{{ shot("tutorial/15-post-editor", '📝 Posts') }}

Discord → Posts is for anything else you want the bot to post and keep up to date: announcements, events, sign-ups, FAQs, extra rules, and the 💌｜feedback message.

  1. Press + New post.
  2. Pick the Channel, then write it like the Start here message: Title, Stripe colour, sections of Text.
  3. Add buttons if you want (see the Buttons part): give a role (e.g. "I'm in" for an event), pick one from a group, a web link, Link Reforger account, My progress, or Give feedback.
  4. Publish.

The picture shows our feedback post: a short message and one Give feedback button.

📋 Changing or removing a post

{{ shot("tutorial/16-posts", '📋 Changing or removing a post') }}

The Posts page lists every post: its channel, whether it's Live, and who changed it last.

  • To change one: press Edit, change it, and Publish again. The bot edits the same message in Discord; it doesn't post a new one, so links and pins keep working.
  • To take one down: open it and press Delete post. It's removed from Discord.
  • Back to posts goes back to the list without changing anything.

Only you and other owners see a post until it's published.

🔗 Link requests

{{ shot("tutorial/17-link-requests", '🔗 Link requests') }}

Members link their Discord to their in-game account from the Start here message. Discord → Link requests is the same queue as the 🔗｜oyb-link-requests channel. Deciding in either place does the same thing.

Waiting for review

  • Approve: links them and gives them the member role. Make sure it's really them first; a matching name alone isn't proof.
  • Reject: turns it down and tells them.
  • If it says No game account matched that name, start typing their in-game name, pick them from the list and press Link.

Linked accounts

Everyone already linked. Unlink takes their rank roles away. Their playtime and XP stay with the game account, so they keep it if they link again.

The bot carries out each decision within a minute.

⚙️ Channels & roles

{{ shot("tutorial/18-channels-roles", '⚙️ Channels & roles') }}

Discord → Channels & roles is for the few things with no page of their own:

Channels

  • Live match board: the self-updating board while a match runs
  • Match results: each finished match's results
  • Weekly leaderboard: the pinned weekly board
  • Rank promotions: rank-up posts

Pick a channel, or leave Keep as it is, then Publish. Channels change within a minute.

Roles

  • Member role: given when someone accepts the rules. Point channel permissions at this role.
  • Unverified label: on people who haven't linked yet.

Role changes need the bot restarting.

Picked on their own page at the top shows which channel every other page is using, with a link to change it. Handy for checking everything is where it should be.

❓ Quick fixes

"I published but nothing changed in Discord"

Wait a minute. The bot checks every 30 seconds. Check the page's status box: if it says Problem, it lists why.

"It's posting in the wrong channel"

Check the Channel box at the top of that page. Remember it saves by itself and is separate from Publish.

"A button says the role can't be given out"

The role has permissions, or it sits above the bot's role. In Discord → Server Settings → Roles, drag the bot's role above it.

"Staff alerts / feedback aren't showing up"

A channel must be picked at the top of that page, and the bot must be able to see and post in it.

"I made a mess"

Discard draft goes back to what's live. On Start here, Start again from the original goes back to the bot's built-in version.

Any other questions, ask in 🗨️｜admin-chat.
