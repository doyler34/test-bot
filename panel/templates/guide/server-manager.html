Managers run the game servers from the Server manager in the sidebar, so nobody has to open AMP. Each server gets its own tabs.

The first time you open the Server manager, a short walkthrough shows you round. Take it again any time.

The server list

The top row shows how many servers are running, the players on, and the memory in use. Each card shows the server's state (Running, Stopped or AMP off), its players, map, memory, mods and admins. Open goes to its tabs.

Overview

  • Start, Restart, Stop, Update control the game. Restart and Stop kick everyone on it, so they ask first.
  • New game (hard reset) stops the server, puts its save aside and starts it again fresh. Everyone on it is kicked, so it asks first. The old save is kept in a backup folder, not deleted.
  • Stop AMP is only for when AMP itself is stuck: it stops the game too.
  • Danger zone at the bottom deletes a whole server. Only the panel's owners can do it. It backs everything up first.

Console

The game's live log, newest at the bottom. Tap ⤢ for full screen. Type a command like #players and press Send. Every command goes in the audit log.

Settings

  1. Use the buttons at the top to jump to a section, or type in the search box.
  2. Change a value or flip a switch. Changed rows are marked, and the counter at the bottom counts them.
  3. Press Save changes. Most take effect when the server next restarts.

Passwords are never shown: type a new one to change it. The Admins list lets you remove people, or add someone by name. Anyone on it is admin and GM in game.

Mods

The mods a server loads are listed at the top, with Remove beside each one. Mods that are already on the box but not loaded can be put back with one tap.

Find a mod shows the Workshop straight away, most popular first. Tap a category (Vehicles, Weapons, Scenarios, Terrain) to narrow it, or a sort to change the order. Type a name and press Search to look for something specific. Each mod shows its picture, author, size and rating.

Press Add on a mod to put it on the list, or Workshop page to read about it first. A mod already on the server says On this server. Changes apply when the server next starts, and the game downloads any mod it doesn't have yet.

To add several at once, tick Select on each mod (or Select all) and press Add selected. The same works for the mods under Downloaded but not loaded, which is handy when a server has lost its list.

You can still paste a mod's 16-character ID under Add a mod if you already have it.

Files

Browse the server's folder, open a text file to edit it, and press Save. The shortcuts jump straight to the config, the mods folder and the logs. AMP rewrites serverconfig.json every time the server starts, so change those values in Settings instead.

Making a new server

Press + New server and work down the steps. Pick a server to copy from and everything fills in with its values. Tick Start it as soon as the game has downloaded to have it run on its own. Its progress shows on the Server manager.
