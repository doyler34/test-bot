The dashboard is the first thing you see after logging in. The top has a card for every server; under them is one server opened up, with its information, a live map of kills, who's on and its charts.

{{ shot("dashboard", "The dashboard: the server cards, then OYB #1 opened up under them.") }}

The server cards

{{ shot("cards", "A server's card.") }}
  • Online or Offline, and a red No admin on when no admin is in game on it.
  • Its name, number of slots and a short description, over its picture. Senior admins set those on Settings → Server cards.
  • Players on, the map, and how fast the server answers (ping).
  • The ★ makes it a favourite: favourites go first. It's saved on this computerphone, so everyone can have their own.
  • Start, Restart and Stop.{% if can("power") %} Restart and Stop ask you to confirm first, because they kick everyone off. They work once the panel is connected to AMP.{% else %} They're greyed out unless a senior admin has given you the start and stop permission.{% endif %}

ClickTap a card to open that server underneath. The cards refresh on their own.

The server panel

Under the cards, the server you picked:

  • The top line has its name and, once a senior admin has added it, the join address. ClickTap the copy button to copy the address, or Join to open it in Steam.
  • Players opens the server's own page on its live feed{% if can("game_admins") %}, Settings its in-game admins,{% endif %} and Full page → the server's own page. See A server's own page.

Server information

Status, how long it's been up, which admins are on (red None when nobody is), the game, map, players, game version, CPU, memory and disk.

Live map

Every kill on the server in the last 30 minutes, on the map: an orange dot is a kill, red a teamkill, purple a kill by AI or nobody, with a line back to where the shot came from. Hover overTap a dot for who killed who, with what, from how far and when. It updates every 30 seconds. More in The live feed and kill map.

{{ shot("map", "The live map, with a teamkill picked out.") }}

Player list and live feed

The box on the right switches between two views. Your pick is remembered.

  • Player List: everyone on now and how long they've been on. Type in the search box to find someone; clicktap a name to open their player page.
  • Live feed: kills, teamkills, joins and Sus flags as they happen, with the same filters as the server page. Handy next to the map.
{{ shot("side-feed", "The same box switched to the live feed.") }}

Charts

CPU, memory, players and network for the last hour, with the latest number in the corner. For longer, and for working out lag, open the Monitor.
