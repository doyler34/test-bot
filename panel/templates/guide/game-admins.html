Senior admins can make players admin in game from Settings → In-game admins, or Settings on a server on the dashboard. The panel changes each server's Admins setting in AMP for you, so nobody needs to log in to AMP.

Making someone admin

  1. Under Make someone admin, start typing their in-game name and pick them from the list, or paste their identity ID.
  2. Tick the servers they should be admin on.
  3. Press Add to the admin list.

Anyone on the list is admin and GM in game, and doesn't need the admin password. Reforger allows up to 20 per server.

Taking someone off

Press Remove next to them on that server's card. Do it on each server they're on.

When it applies

The server only reads its admin list when it starts. Until then its card says Restart to apply. Press Restart now to apply (it kicks everyone and takes a couple of minutes), or let the next scheduled restart do it. Once the server is using the new list, the card says Live.

A new server

A new server, like a modded one, shows up here once it's added to the panel. If its card says the panel doesn't know which AMP instance it is, the server isn't set up in the panel yet.

Every change goes in the audit log and is posted to Discord like kicks and bans, so you can always see who made someone admin.
