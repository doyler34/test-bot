Owners can change what the bot posts in Discord from Discord in the top menu: the Start here message new members see, its buttons, and a greeting when someone joins. No code and no restart: publish, and the bot updates Discord within a minute.

{{ shot("discord-welcome", "The Start here editor, with the preview on the right.") }}

Editing the Start here message

  1. Go to Discord → Start here message. The editor starts with exactly what's in Discord now.
  2. Under Where and how it looks, pick the channel, and change the title and the colour of the stripe down the side.
  3. Under Text, edit the sections. Each has an optional heading. **bold**, *italic* and new lines work like in Discord. Use ↑ ↓ to reorder, ✕ to remove, and + Add section for more.
  4. Watch the Preview as you type. It's roughly how it'll look in Discord.

Buttons

Each button shows as one line: which line of buttons it's on, its colour, its label and what it does. Tap one to edit it; tap its header again to close it. + Add button makes a new one. Up to 5 buttons fit on each of 5 lines.

What it doesWhen pressed
Link Reforger accountOpens the box where they type their in-game name, as always.
My progressShows them what they've done and what's left.
Pick a faction / No factionThe US, USSR and FIA roles, locked once picked, just like before.
Give or take a roleGives them the role; pressing again takes it off. Good for things like event pings.
Pick one role from a groupButtons with the same group name work together: picking one takes away the others. Tick Locked and they can't change it themselves after.
Open a web linkOpens a website, like your rules or a sign-up form.

For the role, pick one of your Discord roles from the list, or choose + Make a new role… and type a name; the bot makes it when you publish. Tick Only for players who've linked to keep a role for linked players.

A button can never hand out a role that has permissions (admin, kick, manage anything). Those are greyed out in the list. The bot's own role also has to sit above any role it hands out: if it doesn't, the page tells you.

Draft, then publish

  • Save draft keeps your changes without touching Discord. Other owners see the draft too. Discard draft goes back to what's live.
  • Publish sends it to the bot. The box at the top then shows when it went up and who published it, or what went wrong (a missing role, the bot's role too low, a channel it can't post in).
  • If something needs fixing, publishing stops and lists what to change, and your work is kept as a draft.
  • Start again from the original puts the editor back to the bot's original Start here message.

Server info & rules

Discord → Server info & rules edits the #servers card: its title and intro, each server's settings (map, player slots, anything players should know), and the in-game rules card under it. The boxes start with what's in Discord now; a box left as it is keeps following the bot's own wording.

Ban messages

Discord → Ban messages sets what a banned player is told and what staff see in their ticket:

  • The DM: on or off, the title and message (tap {server}, {account} or {length} to drop those in), and how to appeal. Pick a channel from the list to add a link to it, like your ticket channel. The reason and when the ban ends are always added underneath.
  • Ban card in tickets: on or off, the channel with your ticket panel, and any other categories tickets land in. Add your panel's address to put a link to the player's page on the card.

Posts

Discord → Posts is for anything else you want the bot to post and keep up to date: announcements, event sign-ups, FAQs, extra rules.

  1. Press + New post.
  2. Pick the channel, then write it like the Start here message: title, colour, sections of text.
  3. Add buttons if you want: give or take a role (e.g. "I'm in" for an event), pick one role from a group, or open a web link.
  4. Press Publish. To change it later, open it from the list, edit, and publish again: the same message is updated, not a new one posted.
  5. Delete post takes it down from Discord.

Server names

Discord → Server names changes what each server is called everywhere the bot names it: the SERVER STATUS channels, the #servers card, match alerts and results, and the match-notification buttons.

{{ shot("discord-names", "Renaming server 3, with the preview on the right.") }}
  1. Type the new name in the server's box. An empty box keeps the default shown under the server.
  2. Check the preview, then press Publish.

Two servers can't share a name, and a name can't contain · (the bot uses it in the channel names). Discord only lets a bot rename a channel about every 5 minutes, so a SERVER STATUS channel can take that long; everything else changes within a minute.

Join greeting

{{ shot("discord-greeting", "The join greeting.") }}
  1. Go to Discord → Join greeting and tick Greet them.
  2. Choose to post it in a channel, or send it to them privately.
  3. Write the message. Tap {user}, {name}, {server}, {members} or {start} to drop in their mention, their name, the Discord's name, the member count, or a link to the Start here channel.
  4. Press Publish.

The bot only hears about people joining if Server Members Intent is on for it in Discord's developer portal and ENABLE_MEMBERS_INTENT=1 is in its settings. The page warns you if not.
