Uptime and crashes

  • Up, last 24h and Up, last 7 days: how much of the time it was online.
  • Crashes: the server stopping without anyone pressing a button. A crash is posted to the staff Discord channel.
  • Recent events: starts, stops (and who stopped it), crashes, and the server going offline or coming back.

Memory

Reforger servers slowly take more memory the longer they run, and some games leave memory behind when a new mission starts. Too much and the server gets laggy or crashes.

  • A few minutes after a full Restart server, the panel notes what a clean server uses. That's the dashed line on the graph.
  • The graph shows the last 24 hours. Memory stepping up a bit when a mission loads is normal.
  • After you press Restart mission, the panel checks again once the new mission has loaded. If memory is still well above a clean start (over 512 MB more), it warns: the old mission's memory wasn't let go.

When to do a full restart

  1. If you see "Memory didn't clear" on the server page, press Restart server when it's quiet (it disconnects everyone for a minute or two).
  2. If memory climbs higher after every mission restart, that's a leak: restart the server.
  3. Either way, a full restart every 6–12 hours keeps things smooth.
