Server cards

What each server's card on the dashboard shows.

  1. Open Settings → Server cards.
  2. To change a picture, choose a file next to that server (JPG, PNG or WebP, up to 5 MB; wide like 1280×720 works best) and press Upload or Change. The top row, Every server, is the picture for any server without its own.
  3. Type a short Description (like "Milsim / Daily Ops") and the Join address players use (like 185.123.45.67:2001), and press Save. The address gives everyone the copy and Join buttons on the dashboard.
  4. Remove takes a picture off, back to the default.

Sus settings

When a kill pattern is flagged as suspicious, and when it's posted to Discord: how many explosions, headshots, long shots or teamkills in how long. Higher numbers mean fewer flags. Changes apply straight away to every server, and Reset to defaults puts them all back. What each flag means is in Spotting cheaters.
